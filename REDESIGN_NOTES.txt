Saudi Vision Project UI Redesign
================================

What was changed
----------------
- Preserved the same information flow, sections, and content structure.
- Reworked the visual design to a more modern, executive presentation style.
- Applied the requested Saudi identity palette:
  - Green:   #006C35
  - White:   #FFFFFF
  - Gold:    #C5A358
  - Purple:  #913191
- Added a more premium hero section, glassmorphism navigation, refined tab navigation, and improved cards/section panels.
- Made purple a visible but controlled accent, so it enhances the government-modern feel without overpowering the Saudi green identity.
- Improved visual hierarchy, spacing, shadows, borders, and readability.
- Kept Arabic/English language switching intact.

Important technical adjustment
------------------------------
- Updated package.json to use @lovable.dev/vite-tanstack-config ^1.2.0 so npm install / npm ci can work without the private package auth issue.
